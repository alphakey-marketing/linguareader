# LinguaReader 🈶

A self-hosted, LingQ-inspired Japanese immersion reading platform. Learn Japanese through real native content — YouTube videos, podcasts, articles, and ebooks — with interactive vocabulary tracking, AI-powered definitions, audio sync, and spaced repetition. No subscription fees.

---

## ✨ Features

- **Interactive Reader** — Color-coded vocabulary by knowledge state; tap any word for instant JMdict lookup
- **Content Import** — Paste URLs, import YouTube subtitles, upload MP3s/podcasts (auto-transcribed), or load EPUB ebooks
- **Audio Sync** — Sentence-level highlighting as audio plays; click any sentence to seek
- **AI Definitions** — Claude Haiku provides context-aware translations for ambiguous words and full sentences
- **Vocabulary Tracking** — Known-words counter with 6-stage learning states persisted across all content
- **SRS Review** — SM-2 spaced repetition with original-sentence context cards; optional Anki sync
- **Progress Dashboard** — Known words over time, words read, listening hours, study sessions
- **TTS Generation** — Voicevox (local) generates natural Japanese audio for text-only lessons
- **Furigana Toggle** — Ruby annotation above kanji, togglable per session

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- Docker (for Voicevox TTS)
- Python 3.10+ with `yt-dlp` installed (`pip install yt-dlp`)
- Supabase project (free tier)
- Anthropic API key (Claude Haiku)
- OpenAI API key (Whisper transcription)

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/lingua-reader.git
cd lingua-reader
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Environment Variables

Copy the example env file and fill in your keys:

```bash
cp .env.example .env.local
```

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# AI / Transcription
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...

# Voicevox (local Docker)
VOICEVOX_URL=http://localhost:50021

# JMdict SQLite path (after running setup)
JMDICT_DB_PATH=./data/jmdict.sqlite
```

### 4. Set Up the Database

Run the Supabase schema (see `supabase/schema.sql`):

```bash
# Via Supabase CLI
supabase db push

# Or paste supabase/schema.sql directly into the Supabase SQL editor
```

### 5. Set Up JMdict (Local Dictionary)

```bash
npm run setup:jmdict
# Downloads JMdict XML and converts to local SQLite (~30MB)
```

### 6. Start Voicevox (TTS)

```bash
docker run -p 50021:50021 voicevox/voicevox_engine:cpu-ubuntu20.04-latest
```

### 7. Run the Dev Server

```bash
npm run dev
# App available at http://localhost:3000
```

## 🎨 Vocabulary Color States

| Color | State | Meaning |
|---|---|---|
| 🔵 Blue | `0` — Unknown | Never seen before |
| 🟡 Yellow (light) | `1` — Learning 1 | Saved once |
| 🟡 Yellow (mid) | `2` — Learning 2 | Seen a few times |
| 🟠 Orange | `3` — Learning 3 | Becoming familiar |
| 🟢 Green | `4` — Learning 4 | Almost known |
| ⚪ White | `5` — Known | Fully acquired |
| ➖ Faded | `99` — Ignored | Proper nouns / irrelevant |

## 📦 Content Import Methods

### Paste Text
Paste raw Japanese text directly. Tokenised instantly in-browser.

### URL Import
```
https://your-site.com/article → Readability.js strips to main text → Lesson created
```

### YouTube Import
```
https://youtube.com/watch?v=... → yt-dlp fetches JA subtitles → Timestamped lesson
```

### Audio / Podcast Upload
```
Upload MP3 → Whisper transcribes (word-level timestamps) → Synced reader + player
```

### EPUB Upload
```
Upload .epub → Chapter extraction → Each chapter as individual lesson
```
